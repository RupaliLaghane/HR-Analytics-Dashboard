# HR Analytics Dashboard

## 📊 Project Overview

This project is an HR Analytics Dashboard created using Tableau.

The dashboard provides insights into employee data, workforce trends,
department performance, employee demographics, and other important HR metrics.

## 🛠️ Tools & Technologies

- Tableau
- Excel
- Data Visualization
- Data Analysis

## 📌 Dashboard Features

- Total Employees
- Employee Demographics
- Gender Analysis
- Department Analysis
- Employee Attrition
- Job Role Analysis
- Age Distribution
- Salary Analysis
- Interactive Filters

## 📈 Key Insights

The dashboard helps HR teams understand employee trends and workforce
characteristics through interactive visualizations.

## 📂 Project Files

- `HR-Analytics-Dashboard.twbx` — Tableau packaged workbook
- `README.md` — Project documentation

## 🎯 Objective

The objective of this project is to analyze HR data and present
important workforce insights through an interactive Tableau dashboard.
